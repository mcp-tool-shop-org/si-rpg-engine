## Q4
ANSWER: Belief records: in the hash. Relationship axes: in the hash. Raw episode log: in the hash as admitted event digests, and the log body is derivable, because an episode is an admitted event plus the intent that caused it, never a line's text. Consolidated reflections: in the hash, as admitted memory writes. The second-sim worry is real but misdiagnosed. It is not the episode log that breaks replay-from-seed; it is the proposals. The seed never generated the model's intents or reflections. Once a model proposes during play, replay is seed plus the input log, and admitted proposals are inputs in that log. Phase 0 says "Replay restores that state" as if the seed suffices. It does not, and saying so is the difference between a save and a second sim.

- relationship axes: in the hash
- raw episode log: in the hash (digests of admitted events); line text out
- consolidated reflections: in the hash (admitted writes, recorded as inputs)
