# Dispatch — host binding

2026-09-30. Main is `25d2554`, the mesh-refusal merge. The picture's engine half has been standing since the host consult (`docs/consult-reply-claude-host-01.md`, verdict revise): `draw` is guarded, and a host that throws is detached while the quantum completes; `advance()` runs one quantum and the pump fires once per timer fire; a restore does not draw. `packages/host` serves a page, a newline-delimited frame stream, and an intent door on loopback, and `fixtures/first-scene-played.json` proves a person's input reaches the law through it. What nothing in the tree writes down is what a host binds to. The stream's records, the door's request and answer, the blend rule, and the no-second-collider line live only in the code and in `docs/PHASE-0.md`'s table. A browser or Godot host today binds by reading `server.js`. The README names the state: a host binding is the open line.

## The choice, stated contrastively

The conservative course keeps the debug view as the only reader of the stream and documents nothing. The next host then binds against an implementation, and a field renamed in code drifts silently until two machines disagree about what the wire said. This slice takes the other course. The socket becomes a written, versioned contract: its records and the intent door are named field by field, the host-side rules are stated, and a reference client that imports nothing from `packages/` plays the fixture through the socket in the suite. The test that drives it imports the session. The debug view keeps working as it does; what changes is that a host never has to read the source.

## Pins

1. **The contract.** `docs/host-binding.md` names the socket exactly as the code speaks it.
   - The stream: `GET /frames` answers newline-delimited JSON — the world record once, then the current frame record, then one line per committed frame. A slow client misses lines and loses nothing: every frame was hashed and frozen before a host saw it.
   - The world record: `kind: "world"`, `version`, `dt`, `colliders`, `zones`, and `goal` when the world names a goal whose zone exists. A collider is an `id` and the six bounds `minX`, `maxX`, `minY`, `maxY`, `minZ`, `maxZ`. The quaternion `qx`, `qy`, `qz`, `qw` is written only when the collider names one; the fixture's three colliders name none. A zone is an `id` and those six bounds. The world file stores a goal as an actor and a zone id; the record's `goal` is that zone.
   - The frame record: `kind: "frame"`, `tick`, `hash`, `bodies`, `door`, `zone`, and `minds` when the world has minds. A body is an `id` plus sixteen numbers: `x`, `y`, `z`, `vx`, `vy`, `vz`, `qx`, `qy`, `qz`, `qw`, `wx`, `wy`, `wz`, `hx`, `hy`, `hz`. `door` is the sim's tick at which the goal was first reached, or null, and it stays that tick. `zone` is the driven actor's zone id, or null. A mind is `body`, `sight`, `x`, `y`, `z`, `beliefs`, and `goals`. A live belief keeps `subject` as text, `key`, and `value`. A goal on the wire is `index`, `kind`, `met`, `metTick`, and either `zone` or `target`.
   - The intent door: `POST /intent`. A body over 4096 bytes answers 413 with an empty body and the connection is destroyed. A body that is not JSON answers 400 `{ admitted: false, reason: "not json" }`. A parsed body answers 200 with the admission — `admitted: true, quanta, hash`, or `admitted: false` with the reason. An intent is `actor` and `verb` (defaulting to `walker` and `move`), and one of `direction` or `target` (a point `{ x, z }`, a body, or a zone). `up` and `down` are refused with `move has no vertical; click a point`. Neither a direction nor a usable target is refused with `an intent needs a target or a direction`. A parsed value that is not an object is refused with `an intent is an object`. A `push` names the nearest other body within the rule's range. A hash the client sends is ignored: the adapter stamps the newest committed hash, which is what the admission returns.
   - The host-side rules. Keep the last two committed frames received and blend them by body `id` over wall-clock `dt`; a position step larger than the body's speed times `dt`, plus `1e-6`, is a cut; a body present in one frame of the pair is drawn where it is committed; the first frame draws as committed. A host keeps no second collider, and a computation whose result becomes a field of an intent reads committed frame fields only — the consult's scar. The law keeps the physics step.
   - The tick-side guarantees. `submit` refuses an intent whose `frameHash` is not the newest (`stale frame: …`). A host that throws is detached and the quantum completes. The pump fires once per timer fire at 16 ms, about two percent slow, and the tick's step does not change. A restore does not draw; hosts see the next committed frame.
2. **The version.** The world record gains `version: 1`. A host that reads a version it does not know refuses to bind rather than guess; records evolve like the model-call records did, where a made-older form still verifies under its own rules. On main the stream's first record names no version, and this pin's test is red there.
3. **The drift check.** The contract carries each record's field list in a fence the suite parses, and a test diffs those lists against the records a session writes — a scene with minds and one without. A collider's quaternion, the world record's `goal`, and the frame record's `minds` are listed as optional. A required field missing from a record, a field the contract does not name, or an optional field written when the source did not name it, fails with the field named. The check goes red on a renamed field the way the translation check goes red on a dropped token.
4. **The reference host.** `harness/binding.test.js` runs a session and its server on an ephemeral loopback port with no pump. The test imports the session so it can start the server and advance the session in process. The client in that file speaks only the socket: `fetch`, and no import from `packages/`. The client reads the stream's head and asserts the contract's shape, posts a move intent to a point, and receives an admission whose hash is the session's own current frame hash. A body that is not JSON answers the named refusal, and an intent with neither direction nor target answers its reason. The frame lines the client receives equal the session's own committed frames at those ticks, byte for byte. The client never calls a package: the socket alone is the proof.
5. **The actor.** `packages/host/session.js` names `walker` twice: the frame record's `zone`, and the intent's default actor. The session's driven actor becomes the world file's goal actor, and `walker` only when there is no scene (the fixture's actor). On main, a session over a world whose goal actor is not `walker` reports `zone: null` while the actor stands in a named zone; this pin's test drives such a world with a goal actor `porter`, and it is red on main.
